Country war deployment (additive; preserve Saves, existing ledgers and old website assets)

1. Build the canonical web client, then node tools/build-accounts.cjs.
2. Deploy build/accounts/index.ts to the existing soulbeast-accounts Edge function using the existing verified-account configuration.
3. Set a freshly generated server secret SB_COUNTRY_WAR_JOB_SECRET in Edge. Store the identical value in Supabase Vault as soulbeast_country_war_job. Never put it in a browser bundle or this file.
4. Run server/country-war/001-weekly-schedule.sql. It wakes at daily 22:00, midnight, and Sunday 23:59 Asia/Bangkok for test/live separately. Monthly settlement runs on the first at midnight. Late jobs settle daily, weekly and monthly boundaries in chronological order before ownership/member mutations; entitlements and letters are idempotent.
5. Publish the new hashed client assets, country-war map PNG and account HTML together after the backend is ready. Existing client versions can still save; the server restores their immutable country field automatically.
6. Verify new-character country selection, legacy first-time choice, daily action, 2-player teams with PVP pets, roster privacy, weekly letters, and exactly-once reward credits in test before live participation.

Storage: existing CAS/receipt transaction stores namespaced cw: rows in GuildState; no new player-save import or destructive migration. Gold uses Camp delta, coupons use CouponCredits. Both are the existing authoritative ledgers, not client-supplied rewards. HP/MP lives in the country's roster snapshot and does not overwrite forest HP.
Nation is per character. Old characters choose once. New characters choose during creation. Rewards require at least one successfully spent daily action (move, attack or explicit defend) within the settlement period. Entry, country choice, team changes, slot occupancy, passive assistance/defense, death and mailbox reads never qualify. Daily/weekly pools are divided only by eligible characters. Monthly prizes are per eligible character.
Reward eligibility uses only server-controlled lastSpentActionAt, recorded on successful active actions. Every mutation settles elapsed reward boundaries before replacing the action timestamp. Old entry/occupancy timestamps are not interpreted as proof of a spent action. Daily periods run from the previous 22:00 Bangkok to the next 22:00; weekly periods run Sunday 23:59 to Sunday 23:59; monthly periods are calendar months. Continuous offline occupants must spend a new action within each reward period; merely retaining a slot does not renew eligibility.
Assisting and defending do not spend the passive participant's daily action. Death from any cause immediately releases the slot and blocks all active actions and team changes for the remainder of that Bangkok day. Respawn at the home capital, full HP/MP, at 00:00 the next day. Respawn does not automatically reclaim a defense slot or count as participation.
Battle is one randomly selected defender pair per daily attack. All surviving defenders must leave through defeat before a base changes hands. Successful attackers enter only if there is capacity. Empty enemy bases are captured without a fabricated battle.
Pair combat uses the existing PVP team validator and combat calculations, with a 120-action draw limit for the larger two-player sides. No manual command, item, seal or roster switch API is available in combat.
The preview server tools/serve-country-war-preview.cjs binds only 127.0.0.1 and uses an in-memory workbook. It never calls production services or changes a real character.
Daily reward pool: village 10 gold, city 100 gold, capital 1000 gold. Weekly pool: village 100 gold + 1/8 coupon, city 1000 gold + 1/2 coupon, capital 4000 gold + 1 coupon. Equal shares among eligible participants use exact fractional carry. Initial complete-country totals: daily 1560 gold; weekly 9600 gold + 5 coupons.
Monthly score: village 1, ordinary city 4, capital 16. Each nation starts on 48 points. Equal scores share competition rank (1,1,3 or 1,2,2). All three nations remain in rankings, including countries without members. Every base, including capitals, can be captured as explicitly confirmed by the user.
Monthly prizes are per character, not divided: rank 1 gets 10 coupons, rank 2 gets 5 coupons, rank 3 gets 1000 gold. The payout and reset are one CAS transaction. Preserve fraction balances, country identity and all forest saves. Restore every base to its original nation and every active member to own capital, full HP/MP, new daily action. Archive the previous standings/ownership in cw:season:YYYY-MM.
Flags and five battlefield PNGs are under assets/ui/country-war; prompts/provenance are content/country-war-art-v1.json. Terrain is fixed to the location, independent of its present owner. No new manual combat actions or potions are exposed.
Capital defense: 32 registered characters, first come first served through the same CAS transaction as daily actions. Registration consumes the daily defend action. Capital reserves are unlimited, do not occupy slots and are never selected as defenders. Living registered guards neither heal at the capital nor refresh their PVP roster. The healing lock persists through travel until death/respawn or season reset, preventing a leave-and-return heal bypass. Non-guard reserves heal automatically. Capturing attackers enter free defense slots without a free heal.
If a home capital is captured, the country's dead characters still respawn there as noncombat reserves; reserve characters never prevent capture. Their current location and its neighbors remain visible so they can leave and retake territory. Monthly reset restores original ownership and clears guard registrations, pending deaths and guard healing locks.
