ตำนานผนึกอสูร — ผนึกสำรองและภาพสกิล

แพ้โจรป่า/นักเดินทาง: โอกาสขโมยผนึกสำรองยังคง 40% ขโมยสูงสุด 1 ตัวต่อการพ่ายแพ้
เลือกได้เฉพาะอสูรที่พกในกระเป๋า ไม่อยู่ในทีมคู่หู ไม่ได้ออกสู้ในศึกนั้น และไม่ได้พักค่าย
อสูรคู่หูที่หมดสติยังปลอดภัย หากไม่เหลือผนึกสำรองจะไม่เสียอสูร
เงิน EXP และไอเทมใช้กติกาเดิม เซฟเดิมใช้ต่อได้

สกิลทั้ง 498 ท่ามีภาพประกอบ เลือกจากภาพวาด 64 แบบตามธาตุและผลของท่า
ปุ่มแสดงภาพ ชื่อ MP และข้อมูลเดิม รองรับมือถือและ PVP
ใช้ atlas WebP เพียงภาพเดียว และย้ายภาพ/เสียงฝังออกเป็นไฟล์ binary เพื่อลด base64
ภาพเนื้อเรื่อง 37 ฉากบีบอัด WebP โดยคงความละเอียดเดิม

อัปโหลด index.html พร้อมโฟลเดอร์ assets ทั้งหมด รักษาเส้นทาง assets/media assets/skills assets/story
ใช้โดเมนเดิมและ Ctrl+F5 เซฟเดิมไม่ถูกลบ
Code.gs เหมือน Adventure ที่ Deploy Version 5 แล้ว ไม่ต้อง Deploy ใหม่สำหรับการเปลี่ยนครั้งนี้
ไฟล์ ZIP เป็นชุดอัปโหลดเว็บ ไม่มี Code.gs หรือข้อมูลเซฟผู้เล่น
ไม่รวมต้นฉบับ PNG ของภาพสกิลใน ZIP เพื่อคุมขนาด
