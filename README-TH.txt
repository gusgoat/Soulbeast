SOULBEAST — Supabase online migration
หน้าเกมยังอยู่ GitHub Pages ส่วน API/ฐานข้อมูลออนไลน์อยู่ Supabase
คงรหัสผู้เล่นและ PIN เดิม กติกาอสูร ไอเท็ม คูปอง และการันตีกาชาเดิม
เซฟ/คูปอง/รางวัลบันทึกเป็นธุรกรรมเดียว ป้องกันคำขอซ้ำและการเขียนทับเมื่อคำขอชนกัน
การสร้าง/เข้าห้องบอสโลกบันทึกเซฟและสร้างห้องในคำขอเดียว
เมื่อเซฟออนไลน์ต่างจากในเครื่อง ระบบให้ยืนยันโหลดก่อนเขียน และเก็บสำเนาเซฟในเครื่องก่อนแทนที่
ไม่มีเซฟผู้เล่น PIN hash รหัสผ่านฐานข้อมูล หรือคีย์ลับใน ZIP นี้
ไฟล์ index.ts และ SQL เป็นโค้ดสำหรับดูแลเซิร์ฟเวอร์ ไม่ใช่ข้อมูลผู้เล่น
คู่มือแอดมิน: ADMIN-GUIDE-TH.md
ต้องติดตั้ง API/SQL นำเข้าข้อมูลล่าสุด ตรวจ SHA256 และเปิด namespace live ก่อนเปลี่ยนหน้าเว็บ
ผลทดสอบความเร็วอ้างอิงเฉพาะชุดทดสอบและช่วงเวลาที่วัด ความเร็วจริงขึ้นกับเครือข่ายและภาระระบบ
