รุ่นภาพเนื้อเรื่องใหม่และชื่อป่า

วิธีอัปเดตเว็บไซต์
1. สำรองเซฟก่อนอัปเดต เก็บไฟล์เกมเดิมไว้
2. แตก ZIP ทั้งหมด จะได้ index.html, โฟลเดอร์ assets/story, Code.gs และคำแนะนำ
3. อัปโหลด index.html ทับไฟล์เดิม และอัปโหลดโฟลเดอร์ assets โดยคงโครงสร้าง assets/story/*.webp ไว้ข้าง index.html
4. ต้องอัปโหลดภาพทั้ง37ไฟล์ด้วย หากนำขึ้นเฉพาะ index.html ภาพเนื้อเรื่องจะไม่ขึ้น
5. เปิดเว็บไซต์เดิมแล้ว Ctrl+F5 ใช้เซฟเดิมได้ การเปลี่ยนโดเมนอาจต้องนำเข้าเซฟสำรอง
6. ไม่ต้องอัปโหลด ZIP เป็นหน้าเกม ให้อัปโหลดไฟล์ข้างใน แต่ละไฟล์ต่ำกว่า25MB ชุด ZIP นี้ประมาณ24.7MB

สิ่งที่ปรับ
- ชื่อป่าทั้ง7แห่งอยู่ใต้ภาพแต่ละปุ่ม อ่านได้แม้พื้นที่ยังล็อก
- ภาพสร้างใหม่37ฉาก: บทนำ4ฉาก ก่อนเข้าด่านหลัก18ฉาก บทส่งท้ายด่านหลัก12ฉาก ป่าฝึกหัดก่อนเข้า2ฉากและหลังผ่าน1ฉาก
- ภาพเล่าเหตุการณ์ตามข้อความ เช่นรับผนึกจากธาราเทพ ราชาทานุกิ จิ้งจอกและความทรงจำ ภาพผนังสุสาน ความไว้ใจบนยอดเขามังกร หัวใจรัตติกาล และการกลับเมืองพร้อมสหาย
- ทุกฉากมีภาพต่างกัน ภาพแสดงเต็มเหนือข้อความบนมือถือและคอมพิวเตอร์ ไม่มีตัวหนังสือทับเหตุการณ์สำคัญในภาพ
- รูปปกบันทึกเรื่องราวและปกบทส่งท้ายใช้ภาพชุดใหม่ด้วย
- เพลงและปุ่มย้อน/ถัดไป/ข้ามฉากเดิมยังอยู่
- ภาพเนื้อเรื่อง WebP กว้าง1280พิกเซล แยกโหลดเมื่อใช้ ไฟล์ HTML ยังประมาณ22.2MB

Code.gs และเซฟ
Code.gs ในชุดนี้เหมือน Code-Chronicles เดิมทุกไบต์ รอบปรับภาพนี้ไม่ได้แก้เซิร์ฟเวอร์
หากคุณ Deploy รุ่นเดิมพัน/ตั้งค่าล่าสุดแล้ว ไม่ต้อง Deploy เพิ่มเพื่อการปรับภาพนี้
หากยังไม่ได้ Deploy Code-Chronicles ให้ทำตาม README-systems-TH.txt เพื่อเปิดระบบเดิมพันเดิมที่เพิ่มไปก่อนหน้านี้ การปรับภาพไม่ได้หมายความว่าได้อัปเดต Apps Script ให้แล้ว
ไม่ได้แก้สูตรต่อสู้ คูลดาวน์ รางวัล เลเวล ระบบเดิมพัน บอสโลก PVP โครงสร้างเซฟ URL รูปหรือเสียงฝังเดิม

การตรวจ
ตรวจภาพต้นฉบับครบ37ภาพ และตรวจไฟล์WebPทุกภาพเปิดอ่านได้/กว้าง1280พิกเซล
ผ่าน syntax และ VM: ทุกฉากมีภาพใหม่แยกกันครบ37ฉาก ทุกบท/บทส่งท้ายแสดงผลได้ ไม่มีรูปundefined ชื่อป่าทั้ง7อยู่ใต้ภาพ ปุ่มเข้าป่า/บทนำ/รางวัลหลังบอสยังทำงาน และเซฟเดิมยังคงฟิลด์เดิม
ตรวจรูปและเสียงฝังเดิมตรงทุกไบต์ ฟังก์ชันต่อสู้และเซฟหลักเหมือนเดิม และตรวจSHA256ทุกไฟล์ในZIP
ยังไม่ได้ตรวจภาพบนเบราว์เซอร์หรือโทรศัพท์จริง และไม่ได้เชื่อม Google Sheets จริงในงานนี้

ไฟล์เสริม

story-art-prompts.txt คำสั่งสร้างภาพและที่มาครบทุกฉาก
