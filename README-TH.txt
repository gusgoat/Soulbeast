SOULBEAST — Release UI Update
เสียงกาชาใช้ไฟล์เดิม: ชาร์จพลังขณะสุ่ม และเสียงวิวัฒนาการ/ชัยชนะเมื่อได้รับของพิเศษ เคารพการปิดเสียงและระดับเสียง
ผลสุ่มเรียงจากหมวดโอกาสน้อยก่อน (ตามอัตราพื้นฐานก่อนการันตี) และมีข้อความยินดี พร้อมภาพตู้กาชาและปุ่มคู่มือ
โลโก้เกมอยู่กลางด้านบน ปุ่มเพื่อนและผู้เล่นออนไลน์อยู่ข้างตั้งค่า
คู่มือรวมวิธีเล่น6ขั้นตอนพร้อมภาพ สมุดอสูร ตำราอาวุธ และข้อมูลอาชีพ รองรับไทย/อังกฤษ/จีน
อัปโหลดindex.htmlพร้อมassetsทั้งหมดไปยังเว็บเดิม แล้วรีเฟรชCtrl+F5เพื่อรับไฟล์ใหม่ เซฟเดิมใช้ต่อได้
Code.gsตรงกับCommunity Version8ที่Deployแล้ว ไม่ต้องDeployใหม่สำหรับการปรับหน้าจอครั้งนี้
อ่านวิธีจัดการคูปองและแบนผู้เล่นในADMIN-GUIDE-TH.md
ภาพตู้กาชาและหนังสือเป็นภาพประกอบโฆษณา รางวัลจริงและโอกาสดูในหน้ากาชา
