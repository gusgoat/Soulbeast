ติดตั้ง
1. ส่งออกเซฟสำรองก่อนอัปเดต เก็บ Code.gs และไฟล์เกมเดิมไว้
2. นำ Code.gs ในชุดนี้ไปวางแทนในโครงการ Apps Script เดิม → Save
3. Deploy → Manage deployments → เลือก deployment เดิม → ดินสอ → Version: New version → Deploy
4. ใช้ URL เดิม ไม่ต้องสร้างชีตหรือโครงการใหม่ ระบบเพิ่มแท็บ PvpWagers ให้เองเมื่อเริ่มใช้งาน
5. อัปโหลดเฉพาะ index.html ทับบนเว็บไซต์เดิม แล้วกด Ctrl+F5 ไม่ต้องอัปโหลด Code.gs เป็นหน้าเว็บ
6. อัปเดตทั้ง HTML และ Code.gs ก่อนเริ่มห้อง PVP ใหม่ แนะนำให้เล่นแมตช์เดิมให้จบก่อนอัปเดต

สิ่งที่เพิ่ม
• ธาตุทุกชนิดใช้ไอคอน SVG คมชัด มีชื่อสำหรับโปรแกรมอ่านหน้าจอและ tooltip
• ปุ่มสกิลในป่า PVP และบอสโลกมีรูปธาตุข้างชื่อ ไม่ซ้อนตัวอักษร ธาตุอาวุธและธาตุปกติแสดงตามกติกาเดิม
• คู่มือชื่อและรูปธาตุอ่านได้ในตั้งค่า
• ปุ่มเฟืองบนหัวเกม เปิดตั้งค่า: ข้อมูลตัวละคร คะแนน ค้นพบ/จับอสูร ความสำเร็จ เปลี่ยนชื่อ รูปโปรไฟล์ เสียง เซฟออนไลน์ สำรองและโหลดเซฟ
• ย้ายโปรไฟล์/เซฟออกจากหน้าตัวละคร รายละเอียดข้อความ ความสามารถติดตัว สกิลอาชีพ สกิลอุปกรณ์ และรายการตำนานกดเปิด–ปิดได้ หน้าที่มีรูปสายอาชีพยังคงแสดงภาพ
• ปุ่มอัปสถานะอัตโนมัติทั้งทีมอยู่ข้างส่วนตรวจความพร้อม อัปตัวละครและอสูรทุกตัวรวมที่พักค่าย ใช้เฉพาะแต้มที่เหลือ ไม่รีเซ็ตแต้มเก่า และไม่ทำให้อสูรที่หมดสติฟื้นเอง
• หน้าป่าเริ่มด้วยภาพขนาดใหญ่ เลือกรูปแล้วจึงแสดงชื่อ เลเวล ข้อมูล อสูรที่พบ และปุ่มยืนยันเข้าป่า พื้นที่ล็อกยังกดดูภาพ/ข้อมูลได้แต่เข้าไม่ได้
• บทนำเป็นฉากภาพ 4 ฉากก่อนเลือกอาชีพ กดฉากถัดไป/ย้อน/ข้ามได้ มีทางลัดสำหรับผู้มีเซฟเดิม
• แต่ละป่ามีฉากเกริ่นก่อนเริ่ม และบทส่งท้ายหลังชนะบอส รวมป่าฝึกหัด แล้วกลับไปหน้ารางวัลเดิมไม่ทำรางวัลหาย
• บันทึกเรื่องราวเป็นปกภาพสำหรับเลือกชมฉาก ใช้ภาพประกอบและเพลงเดิมที่มีในเกม จัดภาพใหม่พร้อมข้อความสั้นต่อฉาก ไม่ได้สร้างภาพใหม่แยกสำหรับทุกประโยค
• เพลงเปลี่ยนตามฉาก เช่น บรรยากาศหลอน เปียโน สงบ และป่า กดปุ่มเปิดเสียง/ฉากถัดไปครั้งแรกให้เบราว์เซอร์อนุญาตเสียง หากปิดเสียงจะไม่มีเพลง

เดิมพัน (เฉพาะ PVP ระหว่างผู้เล่น ไม่ใช้กับป่า/ค่าย/บอสโลก)
1. สร้างห้องและให้เพื่อนเข้าห้องก่อน
2. ในหน้ารอยืนยัน เลือกไม่เดิมพัน หรือเลือกเงิน ไอเท็มใช้แล้วหมดไป อุปกรณ์ในกระเป๋า หรืออสูร 1 ตัว
3. ไอเท็มและเงินใส่จำนวนได้ อุปกรณ์/อสูรเลือกครั้งละหนึ่งชิ้น/ตัว ฝ่ายละหนึ่งรายการ ทั้งคู่เลือกไม่เดิมพันได้ หรือใส่ของมูลค่าต่างกันได้
4. อสูรเดิมพันต้องพักค่าย ไม่พกติดตัว และไม่ได้เป็นผู้เฝ้าค่าย อุปกรณ์ต้องเป็นของในกระเป๋า ไม่ดึงของที่สวมออกจากตัวละคร
5. กดฝาก/เปลี่ยนของเดิมพัน ระบบบันทึกเซฟและตรวจของบนเซิร์ฟเวอร์ ของที่ฝากพักอยู่ในรายการเดิมพัน จึงออกจากกระเป๋าชั่วคราวก่อนเริ่มสู้
6. ดูของของทั้งสองฝ่ายแล้วค่อยกดยืนยันทีมและเดิมพัน การเปลี่ยนของแม้ฝ่ายเดียวจะยกเลิกคำยืนยันทั้งคู่ ต้องยืนยันใหม่ตามรายการล่าสุด
7. ชนะรับของที่ฝากทั้งสองฝั่ง รวมคืนของของตนเอง แพ้เสียเฉพาะของที่ตนฝาก
8. เสมอ หรือยกเลิกห้องก่อนเริ่ม หรือห้องหมดอายุ คืนให้เจ้าของแต่ละฝ่าย ออกจากห้องหลังเริ่มถือว่ายอมแพ้
9. อสูรที่ชนะเดิมพันส่งไปพักค่าย พร้อมเลเวล/ร่าง/แต้มเดิมและรหัสใหม่ไม่ชนตัวเดิม
10. หากคำขอสะดุด ให้ตรวจห้องหรือเชื่อมเซฟออนไลน์เดิมเพื่อรับผล ไม่ต้องเริ่มตัวละครใหม่ ไม่ลบแท็บ PvpWagers เพราะใช้คืนของและตรวจว่าโอนไปแล้วหรือยัง

รักษาระบบเดิม
PVP30วินาทีหมดเวลาเลือกท่าอัตโนมัติ/เสมอ30เทิร์น บอสโลก15วินาที ออโต้ นาฬิกาเตือน สมุดอสูร100ตัว ความจุ5/8ตัว เสียง135ไฟล์ รูปและเซฟเดิมยังอยู่
ไม่ได้เปลี่ยนสูตรดาเมจ คูลดาวน์ เลเวล รางวัลป่าหรือบอสโลก URL เดิม ข้อมูลใหม่เพิ่มแบบต่อยอด
ไฟล์ HTML ประมาณ22.2MB ต่ำกว่า25MB และฝังรูป/เสียงไว้แล้ว ไม่ต้องมีโฟลเดอร์ assets ข้างไฟล์

การตรวจ
ผ่าน syntax และ VM/DOM/บริการ Sheets จำลอง: ธาตุทุกชนิด ปุ่มสกิล หน้าตั้งค่าและหน้าหลัก อัปแต้มทั้งทีม/อสูรหมดสติ ภาพเลือกป่า บทนำ/เข้าป่าจริง/ชนะบอสและกลับหน้ารางวัล
ผ่านเดิมพัน: จำนวนและความเป็นเจ้าของ พักของ เปลี่ยนรายการ/ยืนยันเก่า ชนะ/แพ้/เสมอ/ยกเลิก/ห้องหมดอายุ ไม่โอนซ้ำเมื่อส่งคำขอซ้ำหรืออัปโหลดเซฟเก่า และกู้รายการโอนที่สะดุดจากผลห้องที่บันทึกไว้
ผ่านระบบออนไลน์เดิม: PVP/บอสโลก สิทธิ์ MP นาฬิกา ออโต้ รางวัลและเซฟ ตรวจรูป/เสียงฝังเดิมตรงทุกไบต์ และสูตรต่อสู้หลักไม่เปลี่ยน
ยังไม่ได้ Deploy หรือทดสอบกับ Google Sheets จริง และยังไม่ได้ตรวจภาพ/เสียงบนเบราว์เซอร์หรือโทรศัพท์จริงในงานนี้
