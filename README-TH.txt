ตำนานผนึกอสูร — ม่านหมอกและอสูรในตำนาน

อัปเดตทั้งสองฝั่ง: อัปโหลด index.html และโฟลเดอร์ assets ทั้งหมดไปยังเว็บไซต์เดิม
วาง Code.gs ใน Apps Script โปรเจกต์เดิม แล้ว Deploy > Manage deployments > Edit > New version > Deploy เพื่อใช้ URL เดิม
เก็บเซฟเดิม ไม่ต้องล้างข้อมูลหรือลบชีต เซฟและภาพสกิลรุ่นเดิมใช้ต่อได้

อสูรหายากใหม่ 8 ตัว: กระต่ายหยกจันทรา, ลิงซ์อัสนี, อาชาบุปผาหยก, ด้วงราชันออบซิเดียน,
วาฬน้อยแสงเหนือ, หมาไนเถ้าเพลิง, นกฮูกปริซึม, เสือดาวหมอกทมิฬ
พบในม่านหมอกของป่าที่ระบุในสมุดอสูรเท่านั้น ร่างเดียว มีสกิลเฉพาะตัวเมื่อ Lv12
ค่าสถานะมากกว่าอสูรทั่วไปคู่เทียบ 20% ที่เลเวลและแต้มเท่ากัน

อสูรในตำนานใหม่ 8 ตัว: อุโรโบรอสปฐมกาล, วาลคิรีรุ่งอรุณ, มังกรดารานภา, เต่าจักรวาล,
พญาราชสีห์สุริยะ, อสรพิษอนันตวารี, วิหคสุญญตา, หมาป่าคราสนิรันดร์
ไม่ปรากฏให้สู้หรือผนึกก่อนชนะบอสจอมมารอย่างน้อย 1 ครั้ง (P.cleared > 0)
หลังปลดล็อก: มีโอกาส 3% ต่อม่านหมอกในป่าหลัก พบ Lv45–52 ไม่พบในป่าฝึกหัด
ค่าสถานะ +20% จากอสูรหายากคู่เทียบใหม่ที่เลเวลและแต้มเท่ากัน และมีสกิลเฉพาะตัวระดับตำนาน
ไม่ปะปนในอสูรทั่วไป อสูรของโจร นักเดินทาง NPC หรือบอสประจำด่าน
ร่างเดียวทั้งหมด ภาพใหม่16ตัวอยู่ใน assets/beasts/mist-beasts.webp

สมุดอสูรมีตัวกรอง ทั้งหมด / ทั่วไป / หายาก / ในตำนาน
แสดงร่างเดียว สกิลเฉพาะตัว สถานที่พบ และเงื่อนไขปลดล็อก
การเปิดดูสมุดไม่เพิ่มประวัติพบหรือจับจริง
อสูรรวม116ตัว สกิลรวม514ท่า ข้อจำกัดเดิมของการพกอสูรและผนึกยังคงเดิม

PVPทีมอสูรใหม่, ตัวกรอง, ภาพ, สกิล และกติกาโจรขโมยเฉพาะผนึกสำรอง
