ตำนานผนึกอสูร — ภาพสกิลเฉพาะตัว

เพิ่มภาพสกิลเฉพาะที่ไม่ซ้ำกันรวม114ภาพ:
- อาชีพ63อาชีพ รวมอาชีพเริ่มต้นและอาชีพขั้นสูง อาชีพละ1ท่าจากสกิลที่มีอยู่แล้ว
- อสูร51ตัว: หายาก18 ตำนาน8 และอสูรที่มี3ร่างอีก25ตัว ใช้ภาพกับสกิลเฉพาะตัวของร่างสุดท้าย
สกิลอื่นใช้ภาพธาตุ/ประเภทเดิม ภาพเฉพาะตัวมีกรอบทองและดาว ✦
แสดงในปุ่มต่อสู้ PVP รายการสกิล สมุดอสูร และรายการอสูร
ไม่เปลี่ยนชื่อ ความแรง ค่าMP คูลดาวน์ กติกาเรียนสกิล หรือเงื่อนไขร่างพัฒนา
ภาพมาจาก ImageGen โดยออกแบบตามท่าของแต่ละอาชีพ/อสูร ไม่ใช้ภาพเดียวกันวนสำหรับสกิลเฉพาะตัว

อัปโหลด index.html พร้อมโฟลเดอร์ assets ทั้งหมด รวม assets/skills/signatures-job.webp และ signatures-pet.webp
เซฟเดิมใช้ต่อได้ ควรเปิดโดเมนเดิมแล้วรีเฟรช Ctrl+F5
Code.gs ไม่เปลี่ยนจาก Version6 ที่ Deploy แล้ว ไม่ต้อง Deploy ใหม่
ภาพเนื้อเรื่องทั้ง37ฉากยังอยู่ ปรับความกว้างสูงสุด1152px และ WebP เพื่อคุมขนาดรวมต่ำกว่า25MB
ระบบอสูรม่านหมอก16ตัว ตัวกรองสมุด และเงื่อนไขปลดล็อกตำนานหลังจอมมารยังทำงานเหมือนเดิม

ทดสอบmappingครบ114ภาพ ทุกภาพมีช่องatlasเป็นของตัวเอง ทดสอบกติกาสกิลและเซฟเดิมไม่เปลี่ยน
ตรวจหน้าจอมือถือในเบราว์เซอร์ ไม่ใช้เซฟจริงของผู้เล่นเพื่อสร้างตัวละครทดสอบออนไลน์
