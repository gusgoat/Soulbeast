ตำนานผนึกอสูร — Adventure update

วิธีอัปเดต
1. ส่งออกเซฟสำรองจากตั้งค่าก่อนอัปเดต เก็บเกมรุ่นเดิมไว้
2. แตก ZIP นำ index.html และโฟลเดอร์ assets ทั้งหมดอัปโหลดแทนชุดเดิม โดยคง assets/story/*.webp ไว้ข้าง index.html
3. เปิด Apps Script โปรเจกต์เดิม วาง Code.gs ทับโค้ดเดิมทั้งหมด แล้วบันทึก
4. Deploy → Manage deployments → ดินสอ → Version: New version → Deploy เพื่อคง URL เดิม ไม่ใช่แค่กดบันทึก
5. เปิดเว็บที่โดเมนเดิมแล้ว Ctrl+F5 เซฟเดิมในเครื่องยังอยู่ ถ้าเปลี่ยนโดเมนให้นำเข้าเซฟสำรอง
URL เดิม: https://script.google.com/macros/s/AKfycbzYutJocT-RQAmtCVgY2IT2CerXCjO8fwfn7DBprf3qL9pb3atm2Q0-fyj-TLP_kmVF8g/exec
ไม่ต้องลบชีตหรือข้อมูลผู้เล่นเดิม แนะนำจบห้องต่อสู้เดิมก่อนอัปเดตทั้งสองฝั่ง
ไฟล์ Code.gs สำหรับ Apps Script ไม่ต้องวางในโฟลเดอร์เว็บสาธารณะ

สิ่งที่เปลี่ยน
- ปุ่มป่าหน้าเมืองและแถบล่างใช้ภาพป่าที่เข้าล่าสุด บันทึกเพิ่มใน lastForestId; เซฟรุ่นเก่าที่ยังไม่มีช่องนี้ใช้ป่าหลักไกลสุดที่ปลดล็อกเป็นภาพเริ่มต้น
- ครอปร่างพัฒนา 2 และ 3 รวม 60 ภาพใหม่ตามเส้นแบ่งจริงของแต่ละแถว แทนการหารช่องเท่าๆ กัน และจัดภาพชิดด้านบน
- จู่โจมค่ายและบอสโลกอัตโนมัติทั้งหมด เลือกท่าและเป้าหมายให้ทั้งผู้ผนึกและอสูร ไม่มีปุ่มเลือกสกิลด้วยตัวเอง
- เซิร์ฟเวอร์คำนวณผลและบันทึกรางวัลก่อนส่งภาพการต่อสู้กลับมา เล่นภาพต่อในเครื่องด้วยช่วงประมาณ 0.85 วินาทีต่อเฟรม ไม่ส่งคำสั่งทุกเทิร์นระหว่างดู ปิดหน้าหรืออินเทอร์เน็ตหลุดหลังได้รับผลไม่ยกเลิกผลที่บันทึกไว้ การกลับมาดูผลอาจเล่นภาพซ้ำแต่ไม่ให้รางวัลซ้ำ
- ยังต้องออนไลน์ตอนสร้าง/เข้าห้อง ยืนยันทีม เริ่มค่าย/บอส รับข้อมูลผล และซิงก์เซฟ ไม่ได้ย้ายการตัดสินผู้ชนะหรือการโอนเดิมพันให้เครื่องผู้เล่น
- บอสโลกเล่นได้ 1–4 คน กติกาสิทธิ์ 3 ครั้งต่อสัปดาห์ อสูรคนละ 1 ตัว/นักอัญเชิญ 3 ตัว และการแบ่งคะแนนตามจำนวนผู้เล่นเดิมยังอยู่
- PVP ยกเลิกเวลา 30 วินาทีต่อเทิร์น ยังมีอายุห้องรวม 30 นาทีเพื่อคืนเดิมพันห้องค้าง และยังเสมอเมื่อครบ 30 เทิร์นรวมไม่มีผู้ชนะ
- PVP แบบเลือกท่าเองยังต้องออนไลน์ระหว่างส่งคำสั่งและรออีกฝ่าย หากทั้งสองฝ่ายเปิดออโต้ ระบบคำนวณผลครั้งเดียวและเล่นภาพในเครื่องได้เช่นเดียวกับค่าย ต้องเปิดออโต้ทั้งคู่จึงได้พฤติกรรมนี้
- ผลึกเติบโตอสูรขายในร้านยา: EXP 500 ราคา 300, EXP 2500 ราคา 1300 (ผู้ผนึก Lv15), EXP10000 ราคา4500 (Lv30) ราคาจริงอาจมีส่วนลดตามอาชีพเดิม
- ผลึก EXP ใช้กับอสูรที่พกติดตัวและยังมีสติ นอกการต่อสู้เท่านั้น ไม่ใช้กับผู้ผนึก ไม่เสียของถ้าอสูรเลเวลเต็ม ไม่ลดเลเวลหรือรีเซ็ตแต้ม เซฟเดิมคงอสูรทั้งหมด
- เพิ่มภาพสกิลแบบ SVG ในปุ่มท่าปกติ/PVP และรายการสกิล แสดงสัญลักษณ์ดาบ เวท การรักษา โล่ รูปธาตุ และความเข้มของสกิล โดยแยกจากชื่อและคำอธิบาย
- เสียงและภาพเรื่องราวเดิม 37 ฉากยังอยู่

การตรวจสอบ
ตรวจไวยากรณ์และรันเกมใน JavaScript VM; จำลอง Sheets เพื่อตรวจค่ายอัตโนมัติ, บอสโลก1/3/4คนและนักอัญเชิญ4คน12อสูร, สิทธิ์รายสัปดาห์, เดิมพันและผลซ้ำ, เซฟเก่า, การไม่ใช้ยาเมื่อพลังเต็ม, EXP อสูร, ภาพป่า, สกิลทุกตัว และการเล่นภาพจนจบโดยไม่มีเครือข่ายระหว่างเฟรม
ตรวจภาพรวมครอปอสูรทั้ง60รูปด้วยสายตา ตรวจไฟล์เสียงเดิมไม่เปลี่ยน และ hash ของไฟล์ใน ZIP
ยังไม่ได้ทดสอบในเบราว์เซอร์เกมจริง มือถือจริง หรือเชื่อม Google Sheets จริง และยังไม่ได้ Deploy Code.gs ให้บัญชีของคุณ
