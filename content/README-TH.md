# ข้อมูลเกมแยกตามระบบ

ไฟล์ในโฟลเดอร์นี้เป็นต้นทางข้อมูลของเว็บตั้งแต่Refactorระยะ3 ไม่ใช่ไฟล์ที่มีhashซึ่งสร้างสำหรับเผยแพร่ ห้ามรัน --bootstrap ซ้ำหลังแก้ข้อมูลโดยตั้งใจ เพราะคำสั่งนั้นใช้ย้ายข้อมูลครั้งแรกและจะทับต้นทาง

- elements.js — ธาตุ แพ้ชนะทาง สถานะและความสามารถติดตัว
- skills.js — ท่าพื้นฐาน ตารางสร้างสกิล ร่างแปลง และข้อมูลสกิลที่เพิ่มภายหลัง รวมสกิลบอส
- classes.js — อาชีพ สกิลเสริม จุดเน้นแต้มและคำแนะนำ
- equipment.js — ชนิด/ชื่ออาวุธ ระดับอุปกรณ์ ของพิเศษ/ตำนาน และตารางประกอบอุปกรณ์
- consumables.js — ยา ผนึก และกลุ่มไอเท็มใช้งาน
- beasts.js — อสูรเริ่มต้น สายพันธุ์/ร่างใหม่ อสูรหมอกและข้อมูลที่เพิ่มภายหลัง
- exploration.js — ป่า NPC เหตุการณ์ กับดัก หีบและข้อมูลสุ่ม
- story.js — เนื้อเรื่องหลัก
- localization.js — ข้อความแปลและชื่อภาษา
- presentation.js — ตำแหน่งรูป เสียง แอตลาส รูปสกิลและภาพประกอบ

ข้อมูลใช้ฟังก์ชันคืนตารางเพื่อสร้างข้อมูล ณตำแหน่งเดิมของการเริ่มเกม ไม่ยกการคำนวณไปทำก่อนเวลา บางตารางถูกเพิ่ม/ปรับตามกติกาในruntimeภายหลัง จึงไม่ควรนำค่าหลังปรับแล้วกลับไปแทนตารางตั้งต้น มิฉะนั้นจะได้โบนัสซ้ำ

การสร้างเว็บยังใช้ node work/build-supabase.cjs จากworkspaceเดิม ตัวextractorอ่าน75ตำแหน่งจากโค้ดประกอบแล้วแทนด้วยการเรียกข้อมูลไฟล์นี้ ณตำแหน่งเดิม extraction-map.jsonตรวจhashต้นทางเก่า หากข้อมูลในlegacyเปลี่ยนจะหยุดbuildแทนการมองข้ามโดยเงียบ ต้องย้ายการแก้ข้อมูลมาที่content/หรือทบทวนmapอย่างชัดเจน

สูตรสร้างอาวุธ/สกิลตามระดับและกติกาสมดุลร่วมclient/serverยังอยู่ที่เดิมในรอบนี้ ไม่ได้แปลงตารางสุดท้ายเป็นsnapshot และไม่ได้ย้ายกติกาเซิร์ฟเวอร์หรือแก้เซฟ

ก่อนเผยแพร่: node work/test-refactor-phase3.cjs และ node work/run-refactor-regressions.cjs outputs/refactor-phase3 แล้วตรวจstaging การทดสอบความเท่ากันกับbaselineเป็นหลักฐานของRefactorครั้งนี้ ถ้าจะเปลี่ยนเนื้อหาจริงในภายหลังต้องทบทวนexpected snapshotอย่างตั้งใจ อย่าปิดการตรวจเพื่อให้ข้อมูลที่เปลี่ยนผ่านโดยไม่มีการตรวจ
