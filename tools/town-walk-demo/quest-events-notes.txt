ระบบภาพเหตุการณ์เควส — ระยะ 3

ไฟล์หลัก
quest-events.js: สร้างข้อมูลการ์ดและแสดงภาพ/บทพูด/ผล/เป้าหมายถัดไป
quest-events.css: การ์ดและแถบแจ้งเตือน รองรับจอแคบและพื้นที่ปลอดภัยของมือถือ
quest-event-art.js: ภาพรางวัล 109 รายการ สร้างจาก catalog เดิม
quest-events-preview.html: ตัวอย่างโต้ตอบที่ใช้ผู้เล่นจำลอง ไม่แตะเซฟจริง

ขอบเขต
- เปลี่ยนการนำเสนอ ไม่ให้ระบบภาพแก้ progress หรือแจกของ
- รับงานและเลือกทาง: ยืนยันการรับ/ทางเลือก และค่าใช้จ่ายที่จ่ายแล้ว
- คุย NPC: การ์ดผลในบทสนทนา โดยใช้ภาพผู้พูดที่ตรงเป้าหมาย
- ค้นป่า: การ์ดพบเหตุการณ์ก่อนกด และใบยืนยันหลังทำสำเร็จ
- ล่า/บริการ/กิจกรรม: แถบแจ้งเตือนแบบกดเปิดเอง ไม่เปิด modal อัตโนมัติ
- ส่งงาน: รูปรางวัลและจำนวนจริง พร้อมภาพเป้าหมายถัดไป
- เปิดหีบ: ใช้ id ของที่ได้รับจริง เพื่อเลือกภาพให้ตรงไอเทม
- iframe ของเมนูส่งเฉพาะข้อมูลแสดงผลกลับฉากแม่ ผ่าน origin และ source ที่ตรวจแล้ว

การเติมภาพเฉพาะเรื่องในระยะ 4–5
q.visuals.accept / q.visuals.complete
choice.visuals.accept / choice.visuals.complete (มีลำดับก่อนภาพระดับเควส)
objective.visual.discover: ภาพ/ข้อความก่อนทำ ไม่ใช่คำยืนยันความสำเร็จ
objective.visual.complete: ภาพ/ข้อความหลังสำเร็จ
objective.visual: รูปแบบเก่าสำหรับหลังสำเร็จ ยังคงรองรับ

ข้อมูลภาพแต่ละช่อง
{ art, alt, quote, result, speaker, portrait, grid, frame, row,
  next: { label, place, name, art } }
art/portrait/next.art เป็น path รูป; ไม่ใช้ HTML ในข้อความ
grid=true สำหรับภาพ 3 คอลัมน์ × 2 แถว; frame=0..2 และ row=0..1
รูปเดี่ยวไม่ต้องระบุ grid/frame/row
next เป็นข้อมูลนำทาง ไม่เปิดเมนูหรือรับรางวัลแทนผู้เล่น
